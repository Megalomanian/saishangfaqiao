1MVP 总体架构

一个后端单体服务 + 3 个外部 API + 1 个数据库 —— 没有微服务、消息队列、向量库、Agent 框架

    S --> API["外部 API

用户 / 案件 / 证据 / 方案")]
    S --> L["律师工作台

2一次咨询的核心流程

语音讲案情 → 要件追问 → 案情卡 → 主 Agent 串行调用子 Agent → 树状方案 → 律师复核 → 用户查看
flowchart LR
    A["① 语音 / 文字讲述
ASR 转文字"] --> B["② 要件追问
每次 1~2 问 · 文字卡片"]
    B --> C["③ 案情卡填齐
证据上传 → OCR 回填"]
    C --> D["④ 主 Agent 拆解
串行调用子 Agent"]
    D --> E["⑤ 树状方案
六要素 · 不确定点标注"]
    E --> F["⑥ 律师复核
高亮复核点 · 修改 / 背书"]
    F --> G["⑦ 用户查看
已审核 · 可导出 Word"]

📌 使用说明

1. 打开方式：双击本文件即可在浏览器查看（需 mermaid.min.js 与本文档同目录）。

2. 导出图片：点击每张图右上角的「导出 PNG / SVG」，可直接插入 PPT / Word / 申报书。

3. 修改图：所有图均来自 README.md 中的 Mermaid 代码块，改文档后刷新本页即可同步。
