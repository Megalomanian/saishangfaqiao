2语音案情采集 · 状态机

“前台实习律师”接待流程：全程可打断、可补充，证据采集与追问并行
stateDiagram-v2
    [*] --> 开场引导: 用户进入咨询
    开场引导 --> 自由陈述: 自然叙述
    自由陈述 --> 意图分类: 转写完成
    意图分类 --> 要件追问循环: 加载要件清单
    要件追问循环 --> 证据采集: 用户上传材料（异步并行，不打断）
    证据采集 --> 要件追问循环: 已接收，继续追问
    要件追问循环 --> 案情确认: 关键要件齐备
    要件追问循环 --> 案情确认: 无法补充，标记未知项
    案情确认 --> [*]: 确认后进入 Agent Swarm
    自由陈述 --> 自由陈述: 随时补充新事实
    note right of 要件追问循环: 每次只问 1~2 个最关键问题
全程可打断、可补充

5实施路线 · 时间线

概念验证 → MVP → Swarm 与 Agent Builder → 商业化与生态（各阶段含验收指标）
timeline
    title 塞上法桥 · 实施路线（4 阶段）
    Phase 0 概念验证 : 3~4 周 : 语音转写 + 要件追问 demo : 验收：要件覆盖率 ≥ 80%
    Phase 1 MVP : 10~12 周 : 全流程采集 + 10~15 个场景子 Agent : 验收：一次通过率 ≥ 50%
    Phase 2 Swarm 与 Builder : 8~10 周 : 黑板 + 一致性校验 + DAG : 验收：一次通过率 ≥ 65%
    Phase 3 商业化与生态 : 8~12 周 : 计费 / 订阅 / 广告 / 智能分派 : 验收：付费转化 ≥ 5%

📌 使用说明

1. 打开方式：双击本文件即可在浏览器查看（需 mermaid.min.js 与本文档同目录；若缺失会自动回退到 CDN）。

2. 导出图片：点击每张图右上角的「导出 PNG / SVG」，可直接插入 PPT / Word / 申报书。

3. 修改图：所有图均来自 塞上法桥-可行技术方案.md 中的 Mermaid 代码块，改文档后刷新本页即可同步。
